# Carpeta de Imágenes para Landing Page GUIOS PRO

Puedes colocar aquí imágenes opcionales para enriquecer los módulos y marcas de la landing page.
La plantilla ya cuenta con soporte preparado para usarlas automáticamente si las colocas:

1. **Logos de Software Evaluado** (formato PNG o SVG con fondo transparente, tamaño recomendado 48x48 o 64x64):
   - `postgresql.svg` o `postgresql.png`: Logotipo de PostgreSQL
   - `redis.svg` o `redis.png`: Logotipo de Redis
   - `kafka.svg` o `kafka.png`: Logotipo de Apache Kafka
   - `nginx.svg` o `nginx.png`: Logotipo de Nginx

2. **Diagrama o Ilustración Arquitectónica** (formato SVG o WebP, tamaño recomendado 1200x800):
   - `arquitectura-multicriterio.webp` / `preview.png`: Vista previa o diagrama de flujo metodológico.

3. **Favicon o Isotipo Institucional**:
   - `favicon.ico` o `logo-guiospro.svg`
